Cambios de esta tanda (3 archivos) — color real en los botones
================================================================

Corrección importante: SÍ se puede poner color real a los botones.
Telegram lo agregó en la Bot API 9.4 (9 de febrero de 2026): 'primary'
(azul), 'success' (verde), 'danger' (rojo). Tu bot ya tiene la versión de
la librería (python-telegram-bot 22.8) que lo soporta.

1. utils/entities.py (MODIFICADO)
   - parse_buttons_text() ahora acepta una etiqueta de color opcional al
     principio de cada botón, entre corchetes:
       [rojo] Cancelar - https://enlace.com
       [verde] Confirmar - https://enlace.com
       [azul] Info - https://enlace.com
     (también funciona con red/green/blue o danger/success/primary
     directo). Si no ponés etiqueta, el botón queda con el color por
     defecto de Telegram, como siempre.
   - build_inline_keyboard() ahora pasa ese color real a Telegram
     (parámetro `style` de InlineKeyboardButton).
   - describe_buttons() muestra un emoji del color correspondiente en la
     vista previa del compositor, para que se vea de un vistazo qué
     color tiene cada botón antes de mandarlo.

2. handlers/broadcast.py (MODIFICADO — bot ANUNCIADOR)
   - Actualicé las instrucciones de "🔘 Botones" del compositor de
     anuncios para explicar la sintaxis nueva de colores.

3. handlers/recurring.py (MODIFICADO — bot de moderación, mensajes
   recurrentes)
   - Mismo cambio de instrucciones, para que sea consistente: como los
     mensajes recurrentes usan el mismo parser de botones, ya podés
     ponerles color ahí también sin ningún cambio de código adicional.

No hace falta tocar la base de datos para esto — el color se guarda
dentro del mismo JSON de botones que ya se guardaba antes (buttons_json),
solo se le agregó una clave "style" opcional a cada botón.

IMPORTANTE: este zip NO incluye ningún archivo de base de datos
(bot.db). Nunca reemplaces database/bot.db con nada de un zip mío —
esa carpeta es solo tuya, en el VPS.
